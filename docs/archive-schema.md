# Аудио архивын бүтэц

`app/assets/data/stories.json` — үлгэр, домог, дуу зэрэг аман зохиолын бичлэгийн
бүртгэл. Аппын үгийн сан (`words.json`)-аас тусдаа.

Энэ бүтэц нь **архивын** зориулалттай: аппад хэрэгтэй талбар нь цөөхөн, үлдсэн нь
хойч үед бичлэг ямар үнэ цэнтэйг тодорхойлно. Бичлэг үлдэж, хэн ярьсан нь
мартагдвал ихэнх үнэ цэн нь алдагдана.

## Ерөнхий хэлбэр

```json
{
  "schema": "buriad-archive/1",
  "stories": [ { ... } ]
}
```

## Бичлэг бүрийн талбарууд

### Танигч ба гарчиг

| Талбар | Заавал | Тайлбар |
|---|---|---|
| `id` | ✓ | Тогтвортой танигч, латинаар. Нэг удаа өгөөд хэзээ ч солихгүй |
| `title.b` | ✓ | Гарчиг буриадаар |
| `title.m` | ✓ | Гарчиг монголоор |
| `genre` | ✓ | `үлгэр` `домог` `оньсого` `дуу` `ярилцлага` `зан үйл` |

### Бичлэг

| Талбар | Заавал | Тайлбар |
|---|---|---|
| `audio.app` | | Аппад тараах хувилбар (AAC .m4a). Замыг assets-аас харьцангуйгаар |
| `audio.master` | ✓ | Архивын эх хувь хаана байгаа (WAV 48 kHz 24 bit). Git-д ОРУУЛАХГҮЙ |
| `audio.duration` | | Секундээр |
| `audio.recordedAt` | ✓ | `YYYY-MM-DD` |
| `audio.recordedIn` | ✓ | Газар — сум, аймаг, улс |
| `audio.recordedBy` | ✓ | Бичсэн хүн |
| `audio.equipment` | | Микрофон, төхөөрөмж |

Эх хувийг хэзээ ч дахин шахахгүй. Шахсан файлаас чанар буцаж ирэхгүй.

### Ярьсан хүн

| Талбар | Заавал | Тайлбар |
|---|---|---|
| `narrator.name` | ✓ | Бүтэн нэр |
| `narrator.birthYear` | | Төрсөн он |
| `narrator.birthPlace` | | Төрсөн газар |
| `narrator.dialect` | ✓ | `хори` `ага` `сартуул`. **Хольж нэгтгэхгүй** |
| `narrator.dialectVerifiedBy` | | Аялгууг хэн тодорхойлсон |
| `narrator.learnedFrom` | | Хэнээс сурсан — уламжлалын гинж |

Аялгууны талбар нэг л утгатай. Хэрэв ярьсан хүн хоёр аялгуу холисон бол
тэмдэглэлд бичнэ, талбарыг хоёрдмол болгохгүй.

### Бичвэр

| Талбар | Заавал | Тайлбар |
|---|---|---|
| `transcript.by` | ✓ | Хэн буулгаж бичсэн |
| `transcript.date` | ✓ | `YYYY-MM-DD` |
| `transcript.verifiedBy` | | Хэл шинжээч баталгаажуулсан бол нэр |

### Эрх ба зөвшөөрөл

Хамгийн эрт шийдэх ёстой хэсэг. Ярьсан хүнээс хожим асуух боломж байхгүй байж
болно.

| Талбар | Заавал | Тайлбар |
|---|---|---|
| `rights.consentOn` | ✓ | Зөвшөөрөл авсан огноо |
| `rights.consentForm` | ✓ | Бичгийн зөвшөөрөл хаана хадгалагдаж байгаа |
| `rights.publicInApp` | ✓ | Аппад харуулах уу. **false бол апп огт үзүүлэхгүй** |
| `rights.openToResearchers` | ✓ | Судлаачид ашиглаж болох уу |
| `rights.aiTrainingAllowed` | ✓ | AI сургалтад ашиглаж болох уу — **тусад нь асууна** |
| `rights.nameCredited` | ✓ | Ярьсан хүний нэрийг гаргах уу |
| `rights.withdrawableBy` | | Хэн хожим татан авах эрхтэй |
| `rights.license` | | CC-BY-NC гэх мэт, эсвэл тусгай тохиролцоо |
| `rights.tkLabels` | | Traditional Knowledge Labels (localcontexts.org) |

`publicInApp` нь кодоор мөрдөгддөг: `false` байвал апп ямар ч тохиолдолд
тоглуулахгүй. Хүний алдаанаас хамгаалах давхарга.

`aiTrainingAllowed`-ыг зохиогчийн эрхээс тусад нь асуух ёстой. «Аппад тавьж
болно» гэдэг нь «загвар сургаж болно» гэсэн үг биш.

### Өгүүлбэрийн цаг

Аудио тоглох үед бичвэр зэрэгцэн тодрохын тулд.

```json
"segments": [
  { "start": 0.0, "end": 4.2, "b": "...", "m": "..." }
]
```

`start` ба `end` нь секунд. Үг тус бүрээр биш, **өгүүлбэрээр** тэмдэглэхэд
хангалттай — 5 минутын бичлэгт ~15 минутын ажил.

### Тэмдэглэл

`notes` — чөлөөт текст. Хувилбарын ялгаа, ойлгомжгүй үг, нөхцөл байдал.

## Архивт өгөх бол

Хэрэв ELAR, PARADISEC зэрэг хэлний архивт хадгалуулах бол тэдний метадата
стандарт (OLAC, IMDI) руу энэ бүтцээс хөрвүүлж болно. Талбарууд нь зориуд тэр
стандартуудтай дөхүү нэртэй.
