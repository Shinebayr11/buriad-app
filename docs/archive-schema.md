# Аман зохиолын архивын бүтэц

`assets/data/stories.json` нь архивын нийтийн аппад зориулсан индекс байна. Файлын үндэс нь дараах хоёр талбартай.

- `schema`: одоогийн хувилбар болох `buriad-archive/1` тогтмол утга.
- `stories`: түүхийн объектуудын жагсаалт. Анх хоосон байна.

## Түүхийн талбарууд

| Талбар | Төрөл | Тайлбар |
| --- | --- | --- |
| `id` | тэмдэгт мөр | Архив дотор давтагдахгүй тогтвортой таних тэмдэг. |
| `title.b` | тэмдэгт мөр | Хэл шинжээчээр баталгаажсан буриад гарчиг. |
| `title.m` | тэмдэгт мөр | Монгол гарчиг. |
| `genre` | enum | `үлгэр`, `домог`, `түүх`, `өгүүллэг`-ийн нэг. |
| `audio` | объект | Аппын болон архивын дууны мэдээлэл. |
| `narrator` | объект | Өгүүлэгчийн зөвшөөрөгдсөн танилцуулга. |
| `rights` | объект | Зөвшөөрөл, ашиглалтын тусдаа нөхцөлүүд. |
| `transcript` | объект | Буулгасан болон хянасан хүний мэдээлэл. |
| `segments` | жагсаалт | Дууны хугацаатай зэрэгцсэн бичвэр, орчуулга. |
| `notes` | тэмдэгт мөр | Архивын нэмэлт тэмдэглэл. |

## `audio`

- `app`: аппад багцлах AAC файлын харьцангуй зам.
- `master`: архивын WAV эх файлын байршлын тэмдэглэл. WAV файлыг git-д оруулахгүй.
- `duration`: нийт үргэлжлэх хугацаа, секундээр.
- `recordedAt`: ISO 8601 огноо.
- `recordedIn`: бичлэг хийсэн газар.
- `recordedBy`: бичлэг хийсэн хүн.
- `equipment`: ашигласан төхөөрөмжийн мэдээлэл.

## `narrator`

- `name`: өгүүлэгчийн зөвшөөрсөн нэр.
- `birthYear`: төрсөн он; мэдэгдэхгүй эсвэл нийтлэх зөвшөөрөлгүй бол `null`.
- `birthplace`: төрсөн газар.
- `dialect`: `хори`, `ага`, `сартуул`-ын нэг. Аялгуунуудыг нэгтгэхгүй.

## `rights`

- `consentOn`: зөвшөөрөл авсан огноо; анх хоосон.
- `consentForm`: зөвшөөрлийн баримтын таних тэмдэг эсвэл хамгаалалттай архивын зам; анх хоосон.
- `publicInApp`: аппад нийтэд сонсгох зөвшөөрөл.
- `openToResearchers`: судлаачдад нээлттэй эсэх.
- `aiTrainingAllowed`: хиймэл оюуны загвар сургахад ашиглах тусгай зөвшөөрөл.
- `nameCredited`: өгүүлэгчийн нэрийг нийтлэх эсэх.
- `withdrawableBy`: зөвшөөрлийг буцаах эрхтэй этгээдийн мэдээлэл; анх хоосон.
- `license`: лицензийн таних тэмдэг; анх хоосон.
- `tkLabels`: уламжлалт мэдлэгийн шошгын жагсаалт; анх хоосон.

Бүх boolean зөвшөөрлийн анхны утга `false`. `publicInApp: true` нь зөвхөн аппад нийтлэх эрх бөгөөд `aiTrainingAllowed`-ийг автоматаар зөв болгохгүй. Апп зөвхөн `publicInApp: true` түүхийг харуулна.

## `transcript`

- `by`: бичвэр болгон буулгасан хүн.
- `date`: ISO 8601 огноо.
- `verifiedBy`: бичвэр, орчуулгыг баталгаажуулсан хүн.

## `segments`

Хэсэг бүр `start`, `end`, `b`, `m` талбартай. `start`, `end` нь секундээр илэрхийлсэн тоо бөгөөд `0 <= start <= end` байна. `b` нь баталгаажсан буриад бичвэр, `m` нь монгол орчуулга. Тоглуулагч одоогийн хугацаа орсон хэсгийн хоёр бичвэрийг зэрэг тодруулна.

## Хадгалалт ба нууцлал

Нийтийн JSON-д зөвхөн нийтлэх зөвшөөрөлтэй мета өгөгдөл орно. Зөвшөөрлийн эх баримт, WAV мастер, нийтэд зориулаагүй хувийн мэдээллийг repository-д хадгалахгүй. Бичлэгийг нийтлэх, судалгаанд ашиглах, загвар сургах гурван эрхийг тус тусад нь шалгана.
